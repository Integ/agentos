03 · 安全模型
越危险，越要你点头
L0只读看时间、读笔记自动执行
L1可逆记笔记、开灯自动执行并记录
L2对外场景脚本、MCP 工具每次确认
L3不可逆清空数据、开门锁、装插件确认 + PIN
污点追踪不可信输出之后，一律确认
哈希链审计agentos-taskd --verify-audit
插件沙箱bubblewrap + 资源上限
批准只在屏幕上进行 · 语音不能批准

05 · v0.4
让 Agent 真正成为一等公民

并行 · 线程

默认同时 4 个任务；接着同一段对话说下去。

会提问

缺信息时调用 ask.user，任务进入“等待回答”。

用量与预算

规划轮数 · token · 执行时长，到点即停，如实记为失败。

预授权

agentos preauthorize 事先许可一类 L1/L2 调用；不适用于 L3 和受污染的任务，撤销立即生效。

AgentOS 作为 MCP server

agentos mcp --caller … 让别的 Agent 来用它：只能用清单里的能力，自己不能批准。
